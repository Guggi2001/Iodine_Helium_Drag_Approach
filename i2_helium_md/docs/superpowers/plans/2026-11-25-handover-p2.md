# Handover P2 (presets, battery, regeneration drivers) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build B2 / B3 / h405 from named presets with one driver, and give the legacy runs fixed seeds, proven equal to the committed thesis runs.

**Architecture:** Purely additive. Presets hold physics, `simulation/battery.py` runs and pools, `postprocess/battery_score.py` scores, two thin scripts drive them. The old generators stay until P4.

**Tech Stack:** Python 3.13, numpy, pytest; no new dependency.

**Spec:** `docs/superpowers/specs/2026-11-25-handover-cleanup-design.md` (P2); detail in `docs/POST_THESIS_CLEANUP.md` C5.1, C5.2 as amended by C5.7.

## Global Constraints

- Code needs `[PROCEED TO IMPLEMENTATION]`; commits only on request ("offer commit" = ask).
- No change to constants, RNG draw order, checkpoint schema or `SimConfig` defaults (defaults are P5).
- No existing run directory is written. The new code has no overwrite switch.
- Comparisons are exact for configs and arrays, 4 dp for scores.
- New package code imports nothing from `scripts/`.
- MD cost: one B2 s1 rerun (Task 5); on request only, the three seeded legacy runs (Task 6).

## Review Focus

1. A run directory left half-written by a crash: refused with the missing files named, not skipped or overwritten (Task 2).
2. A finished directory holding a different model: refused with the field diff (Task 2).
3. Pooling with a missing or duplicate-seed member: refused, naming it; fragment pairing preserved (Task 3).
4. B3 runs carry the historical `LQ` label: still recognised as B3 (Tasks 1, 2).
5. One failing member in a batch: started members finish, nothing new starts, the failure is named (Task 2).
