# Handover P4 (delete scripts and data) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every script, test, table and root file off the signed-off allowlist is gone, and nothing that stays needed it.

**Architecture:** Kept tests are cut loose from the scripts first, with those scripts still present to compare against. Then the rows marked `move` or `delete` are removed in one step, driven by the allowlist. Package modules and their tests stay until P5, documents until P6.

**Spec:** `docs/superpowers/specs/2026-11-25-handover-cleanup-design.md` (P4; §4, §6, D4, D10). P3 as delivered: the P3 entry in `drag_migration_log_tier2.md`.

## Global Constraints

- Code needs `[PROCEED TO IMPLEMENTATION]`; deleting needs its own explicit yes on the list printed by Task 4; commits only on request.
- Only rows `move` / `delete` of `docs/handover/ALLOWLIST.csv` are deleted, only inside `i2_helium_md`, only tracked files (`git rm`). Git-ignored run directories stay until P7.
- No test of package physics loses coverage: for each rewired test the assertions stay, only the source of the config changes. A test goes only with the code it tests.
- No package file, constant, default or stored `cfg.json` changes. Figures, tables and data on the allowlist keep their bytes.
