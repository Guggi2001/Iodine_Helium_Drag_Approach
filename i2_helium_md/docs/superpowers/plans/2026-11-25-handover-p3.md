# Handover P3 (rewire figure scripts) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every kept script reads from the package or another kept script, and one driver regenerates all thesis figures.

**Architecture:** The figure scripts keep their own drawing code; only their inputs move. Directory names and Tier-0 configs get one owner each, the chord geometry goes into the package, and oracles against the removed `never` batteries go. A third driver runs every figure script and puts the committed files back.

**Tech Stack:** Python 3.13, numpy, matplotlib, pytest; no new dependency.

**Spec:** `docs/superpowers/specs/2026-11-25-handover-cleanup-design.md` (P3; §4, §6). P2 as delivered: `docs/superpowers/plans/2026-11-25-handover-p2.md` and the P2 log entry.

## Global Constraints

- Code needs `[PROCEED TO IMPLEMENTATION]`; commits only on request.
- Figures pixel-identical and CSVs byte-identical to P0 (`docs/handover/baseline.json`), except the legacy set and the g13 class and column of Decision A. No tolerance is loosened.
- No constants, draw order, checkpoint schema, `SimConfig` default or drawing code changes.
- Committed files in `data/figures/` and the tables in `data/runs/h2b_forward_model/` stay as submitted; no run directory is written.
- Nothing is deleted before P4. The tests that import moved or deleted scripts are rewired in P4, not here.

## Decisions (settled by the user, 2026-11-25)

- **A. The `never` members are dropped.** `tier2_g6_chord_map` and `tier2_g13_shed_timing` read twelve pre-G13 `never` runs (B2, h405). No driver regenerates them, and the allowlist keeps only `decoupled`, so after P5 they cannot be run or loaded. In g6 they feed only oracles, which go. In g13 the class `supp_never` and the column `frac_formerly_suppressed` go. That class is the bare class to within 2 of 1262 ions (B2) and 5 of 2306 (h405), counted over the six members; THESIS_DISCUSSION §16 states the same. The committed g13 tables keep both; every other row and column stays byte-identical.
- **B. Anchors report, tests check.** `tier2_g13_shed_timing`, `tier2_thesis_observable_table` and `tier0_thesis_figure` today stop if a rerun differs from a committed number (4 dp or bit-exact). On another machine or numpy version that can fail on rounding, and no figure is written. The scripts now print `differs from committed: …` and continue; the driver repeats the list at the end and exits 1. The exact checks move into tests (skip without runs).
- **C. `regen_tier2_stage1_events.py` is deleted in P4.** `run_member` always records the events. The allowlist row is already `delete`.

## Review Focus

1. Figures on a fresh clone with no `data/runs`: the missing directory and the driver that makes it are named, no traceback from deep inside a loader (Tasks 1, 5).
2. A figure script fails halfway in the driver: the committed files are back, the other scripts still run, the failure is named, exit code 1 (Task 5).
3. A modified, uncommitted figure in the working tree: the driver refuses before running anything (Task 5).
4. A Tier-0 directory holding another model: refused, not regenerated in place as `ensure_run` does today (Task 2).
5. A regenerated legacy run that does not match its preset: refused, as today in `legacy_continuum_drag_figure` (Task 4).

### Task 5: Figure driver

**Files:** Create `scripts/run_thesis_figures.py`; Test `tests/test_run_thesis_figures.py`

**Interfaces — USER SETTINGS:** `SCRIPTS = "all"` or a list of stems, `OUTPUT_ROOT = data/figures_regenerated`. `main() -> int`. Reads the figure table of `data/figures/README.md`, runs each script once as a subprocess, copies what it wrote to `OUTPUT_ROOT/<chapter>/`, restores the tracked files under `data/`, and prints per figure `identical`, `differs` or `not rendered` with the reason, then the anchor differences. Exit 1 if a figure was not rendered or an anchor differs; `differs` alone is 0 (legacy figures differ by design). The parsing, comparison and restore functions move here from `scripts/handover/baseline.py`, which re-imports them until P6. `OUTPUT_ROOT` goes into `.gitignore`.
