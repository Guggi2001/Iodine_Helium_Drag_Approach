# Handover P0–P1 (baseline and allowlist) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Record the submitted thesis state and produce a signed-off allowlist of everything that stays. Nothing is deleted and no model code changes.

**Architecture:** Two small temporary tools in `scripts/handover/`. `baseline.py` re-renders the thesis figures and classifies each against git HEAD. `allowlist.py` maps figures to their import closure and checks that a hand-decided CSV covers the repo. Both are removed in P6.

**Tech Stack:** Python 3.13 (`python` on PATH), pytest, Pillow, git; nothing new installed.

**Spec:** `docs/superpowers/specs/2026-11-25-handover-cleanup-design.md`

## Global Constraints

- Code needs `[PROCEED TO IMPLEMENTATION]` from the user.
- Commits, tags and pushes only on an explicit request for that action. Where a task ends in "offer commit", stop and ask.
- No change to `i2_helium_md/`, presets, constants, RNG draw order or checkpoint schema.
- `data/runs/` run directories are never deleted or rewritten. Tracked `data/` files end each task identical to HEAD.
- Quote only committed numbers. The last numbers in `THESIS_DISCUSSION.md` are the thesis numbers; the latest section wins.
- The user's uncommitted edit of `scripts/run_single_pulse.py` is left alone.
- Commands run from the project root `i2_helium_md/`.

## Review Focus

1. Uncommitted changes under `data/` when a render starts: refuse, do not overwrite (Task 2).
2. A figure script crashes or an input run is missing: record `not_rendered` with the reason and continue (Task 2).
3. CSVs that differ only in CRLF/LF: identical (Task 2).
4. A script imported by bare name, or through a function-level import: still in the closure (Task 3).
5. A file added or deleted after the allowlist was written: the check fails and names it (Task 5).

def test_png_compares_pixels_not_metadata(tmp_path):
    im = Image.new("RGB", (4, 4), "red")

        b = io.BytesIO(); im.save(b, "PNG", dpi=(dpi, dpi)); return b.getvalue()

def test_crashing_script_is_recorded_and_others_continue(tmp_git_repo):
    # fixture also commits s_bad.py (raises SystemExit("boom")), s_ok.py (rewrites data/x.csv

def test_stale_figure_is_not_called_identical(tmp_git_repo):
